# Sample Final Exam Instructions

This directory contains 6 files for the 2026 sample final exam.

There are 5 question files, all with names `q….dfy`.  Questions 1–4
are worth 10 marks each (40 marks in total); question 5 is worth 5
marks.  The exam is designed to take one hour.

Open and edit each q-file in VS Code to do your exam work. (If you are
doing COMP1600, IGNORE the q5 file; that's meant for COMP6260 students
only.)

Your files **must compile**.  A file with syntax errors (a grey bar or
red triangle in VS Code) will get 0 marks.  Before you finish, check
each file with `dafny verify`, or make sure VS Code shows a green bar.
If you can't finish a proof, leave the statement in place with a
`{}` body: a failing proof costs you only that proof's marks, while
a file that doesn't parse costs you everything in it.
